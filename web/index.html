NOCTIS

OS · Galaxy Edition
--:--

A real Android home-screen launcher written in Kotlin and Jetpack Compose. This is the Phase 1–3 foundation.

Implemented

  • Home screen with a minute-accurate clock and date, wallpaper scrim and a 4-slot dock
  • App drawer: swipe up, live search by name or package, adaptive grid
  • Long-press to pin or unpin apps, saved with DataStore
  • Live refresh when apps are installed or removed
  • NOCTIS colour tokens, edge-to-edge layout, TalkBack labels

Coming later

Themes, folders, widgets, a notification companion, a control center, settings, Galaxy integrations and foldable layouts.

Build it

Open the repo in Android Studio (Ladybug or newer, JDK 17), run it on a device, press Home and choose NOCTIS. Not compiled yet, so expect small fixes on first sync.
